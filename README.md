# Madrasa

Раньше рабочее название было «Устаз-помощник».

Платформа для чтения и заучивания Корана. Работает как Telegram Mini App и как обычный сайт.

Полный план и методика описаны в [PLAN.md](PLAN.md).

## Что уже работает (фаза 1)

- **Два мусхафа на выбор:** мединский (604 страницы) и пакистанский хафизский (610 страниц), оба по 15 строк, со строками как в бумажном мусхафе.
- **Назира:** страница в день на проверку, счётчик прочитанного (цель — 3 джуза), после этого переход к заучиванию.
- **Помощник заучивания:**
  - страница 20 раз;
  - потом по 2 строки: 5 раз глядя, 5 раз не глядя (строки скрываются), 20 раз наизусть;
  - соединение с предыдущими строками 20 раз;
  - в конце весь урок 20 раз.
  
  Последняя нечётная строка присоединяется к последней паре (13–15). Объём урока на день: 2 строки, полстраницы или страница.
- **Счётчик и таймер на одном экране:**
  - большая кнопка «+1» и отмена;
  - время урока с паузой;
  - время последнего повторения и среднее;
  - обратный отсчёт до конца утреннего блока;
  - дневная норма 200 повторений.
- **Сдача:**
  - проверяющий нажимает на слова: один раз — ошибка, второй — замечание по таджвиду (в оценку не идёт), третий — убрать;
  - оценка по 5 баллам: 0 ошибок — 5, 1 — 4, 2 — 3, 3 и больше — 2 и пересдача.
- **Сабки и манзиль:**
  - сабки: выученное из текущего джуза, пачками по 10 страниц;
  - манзиль: выученное остальных джузов, по кругу, с расписанием и напоминанием.
- **Выученное раньше** отмечают джузами, сурами или страницами, и оно сразу идёт в повторение.
- **Дневник** с колонками бумажного дневника: дата, сдано устазу, сабак, сабки, манзиль, повторения, время.
- **Карта прогресса:** все страницы по джузам.
- **Несколько учеников** на одном устройстве, например все дети в аккаунте родителя.
- **Языки:** русский, казахский, английский и арабский (интерфейс справа налево).
- **Все числа методики** меняются в настройках.

Пока прогресс хранится на устройстве. В настройках можно сохранить и загрузить копию.

**Чего ещё нет:**
- ИИ, который слушает и проверяет чтение (фаза 2);
- синхронизация между устройствами;
- напоминания через бота.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # тесты методики
npm run build      # сборка в dist/
```

`dist/` — это обычные статические файлы. Их можно выложить на любой хостинг: GitHub Pages, Vercel, Netlify или свой сервер.

## Подключение к Telegram

1. Выложите `dist/` на хостинг с HTTPS.
2. В @BotFather создайте бота (`/newbot`), затем Mini App (`/newapp`) и укажите адрес сайта. Можно вместо этого задать кнопку меню (`/setmenubutton`).
3. Откройте бота в Telegram. Приложение возьмёт цвета темы Telegram и включит вибрацию на «+1».

## Данные мусхафов

Текст и разметка страниц лежат в `public/data/` и взяты из API Quran.com:
- мединский — KFGQPC Hafs;
- пакистанский — IndoPak 15 строк.

Мединский мусхаф есть в двух изданиях, ученик переключает их в настройках:
- `madani`: издание 1421 года, шрифт QCF2, по файлу на страницу;
- `madani1441`: издание 1441 года, как в приложении Комплекса короля Фахда, шрифт QCF4.
  Разметку строк собирает `node scripts/build-1441.mjs` из открытого пакета quran-qcf4 (данные под MIT),
  слова берёт из `madani`. Шрифты QCF4 распространять нельзя, поэтому приложение берёт их с jsDelivr из того же пакета.
  При переключении выученное и место урока переносятся по словам: на 378 страницах строки разбиты иначе.

Чтобы скачать их заново:

```bash
npm run fetch-mushaf
# качает и разметку, и 604 шрифта QCF (около 94 МБ, в git они не хранятся);
# только шрифты: npm run fetch-mushaf -- fonts
# в облачной среде Claude Node нужен прокси: NODE_USE_ENV_PROXY=1 npm run fetch-mushaf
```

**Шрифты:**
- мединский текст — KFGQPC Uthmanic Hafs (Комплекс короля Фахда, бесплатное распространение);
- пакистанский — Scheherazade New (SIL Open Font License).

## Устройство кода

| Файл | Что внутри |
|---|---|
| `src/method.ts` | Методика: деление на куски, шаги урока, сабки и манзиль, оценки. Чистые функции с тестами в `method.test.ts` |
| `src/store.ts` | Состояние учеников и действия (урок, сдача, повторения) |
| `src/mushaf.ts` | Загрузка страниц и подписи аятов |
| `src/i18n.ts` | Переводы на 4 языка |
| `src/screens/` | Экраны: Сегодня, урок, сдача, повторение, дневник, прогресс, мусхаф, настройки |
| `scripts/fetch-mushaf.mjs` | Скачивание разметки мусхафов |
